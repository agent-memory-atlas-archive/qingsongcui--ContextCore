Claude Code、Cursor 与 Codex MCP 配置 — JSON 转 TOML 指南

对照 Claude Code、Cursor 的 MCP JSON 与 Codex config.toml 配置示例，检查本机服务连接、配置路径和加载结果。

更新于 2026-11-17 · Senrelay 维护者

Claude Code MCP 配置示例

~/.claude.json

{
  "mcpServers": {
    "contextcore": {
      "type": "http",
      "url": "http://127.0.0.1:8420/mcp/"
    }
  }
}

Cursor MCP 配置示例

~/.cursor/mcp.json

{
  "mcpServers": {
    "contextcore": {
      "url": "http://127.0.0.1:8420/mcp/"
    }
  }
}

Codex MCP 配置示例

~/.codex/config.toml

[mcp_servers.contextcore]
url = "http://127.0.0.1:8420/mcp/"

加载与排查

先启动 Senrelay，再保存对应宿主的配置。合并服务区块并保留已有配置，在宿主内重新加载 MCP。检查 contextcore 服务是否连通、工具是否可列出。桌面版适用 macOS 14.0+ Apple Silicon，本机服务地址为 http://127.0.0.1:8420/mcp/。连接失败时先核对进程、端口和宿主实际读取的配置路径。

Load and troubleshoot the connection

Start Senrelay before saving the host configuration. Merge the service block with existing settings, then reload MCP in the host. Check whether contextcore connects and lists tools. The desktop app targets macOS 14.0+ Apple Silicon and the service uses http://127.0.0.1:8420/mcp/. If connection fails, check the process, port, and configuration path loaded by the host.
